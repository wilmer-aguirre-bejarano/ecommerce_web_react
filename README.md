# Ecommerce Web - Multi-vendedor

Proyecto React + TypeScript + Vite con integración Supabase.

## Inicio rápido
1. Copiar `.env.example` a `.env` y completar VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY
2. Ejecutar SQL `supabase_schema.sql` en Supabase SQL Editor
3. Instalar dependencias: `npm install`
4. Ejecutar: `npm run dev`
5. Build: `npm run build`

## Documentación
Ver carpeta `docs/` para arquitectura, desarrollo y seguridad.
